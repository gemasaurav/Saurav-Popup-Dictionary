How to use Saurav Popup Dictionary

  1. Open any app (browser, WhatsApp, PDF, notes etc).
  2. Long-press any word to select it.
  3. In the selection menu that pops up, tap “Saurav Popup Dictionary”.
  4. A small popup window will show the meaning, Hindi meaning, pronunciation, part of speech, synonyms and antonyms.
  5. Tap anywhere outside the popup to close it.

This app has no separate search screen on purpose — it works everywhere automatically, exactly where you select the word.
