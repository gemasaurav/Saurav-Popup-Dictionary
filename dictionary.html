Get it in the text-selection menu

This page can't put itself into the Copy / Select all menu — only an installed app can, via an ACTION_PROCESS_TEXT filter in its manifest. Until the APK is installed, the fastest ways to use this file:

  1. Add to Home screen. Open this file in Chrome → ⋮ menu → Add to Home screen. It then opens full-screen like an app, with one tap.
  2. Select → Copy → open → paste. The input is focused on launch, so it's two taps.
  3. Direct link. Append ?w=courage to the file URL to open straight to a word — useful for a browser shortcut or bookmarklet.

Looked-up words are saved on this device, so anything you've seen once opens instantly with no internet.
